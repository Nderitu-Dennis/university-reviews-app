# University Reviews App

## Overview 
The University Reviews App is a full-stack web platform that allows users to review universities, interact with reviews, and explore fun facts about institutions. Built with Spring Boot, Thymeleaf, and MySQL, it provides a user-friendly and engaging experience.

## Features
* Post, Edit, and Delete Reviews

* Like & Unlike Reviews(not yet)

* University Profile Pages with Details

* AI-Generated Fun Facts about Institutions(not yet)
 
* Google Maps Integration for Locations

* Responsive UI with Tailwind CSS

## Tech Stack
* **Backend:** Java (Spring Boot), MySQL

* **Frontend:** Thymeleaf, Tailwind CSS

* **Authentication:** Spring Security

* **AI Integration:** DeepSeek or Gemini API (Planned Feature)
